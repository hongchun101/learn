# 配套代码示例

本目录提供教程中引用的 Haskell 代码示例,可在 GHC 9.6+ 下运行。

```bash
$ ghci
> :l Ch01/Motivation.hs
```

## 文件

- `Ch01/Motivation.hs` λ-演算概念
- `Ch03/Lambda.hs` Church 编码
- `Ch05/Recursion.hs` 递归示例
- `Ch08/Functor.hs` 自定义 Functor
- `Ch10/Monad.hs` 自定义 Monad
- `Ch20/Json.hs` 简易 JSON

教程中所有代码片段都可在 ghci 中亲手运行。这是 FP 学习的最佳方式。
