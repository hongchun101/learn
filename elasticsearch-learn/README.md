# Elasticsearch 实战教程:从 0 到专家

> 目标:系统化地掌握 Elasticsearch,使其作为搜索与分析引擎的核心组件,达到中高级 / 专家工程师水平。

本教程面向**后端工程师、搜索工程师、数据工程师、运维工程师**以及任何想系统学习 ES 的人。
按章节循序渐进:每章后都配有 **要点速查 / 实操练习 / 思考题**;最后一篇给真实企业级案例。

## 二、环境与前置知识

- **语言**:Java 8+(ES 7.x)/ Java 17(ES 8.x+)。本教程示例以 REST API 为主,不绑死客户端。
- **HTTP 工具**:`curl` 或 Kibana Dev Tools。
- **建议环境**:8GB 内存,能跑单节点 ES + Kibana。
- **前置知识**:
  - 了解 JSON / HTTP / REST。
  - 了解关系型数据库基本概念(可类比理解 ES,但 ES 不是数据库)。
  - 了解 Linux 常用命令。

---

## 三、如何使用本教程

1. **顺序学习**:每章只依赖前面学过的内容,不要跳。
2. **动手实操**:示例请复制到 Kibana Dev Tools 实际跑一遍,只看不动手 ≈ 没学。
3. **思考题**:每章末尾的思考题是检测掌握度的最快方式,建议先独立思考。
4. **速查模式**:已经入门可以当作手册,按目录定位章节快速复习。

## 五、本教程约定

- **API 风格**:以 Elasticsearch 8.x 为准,7.x 差异点会单独标注。
- **示例数据**:所有示例数据均为虚构,用户可随意复制使用。
- **复制运行**:REST 示例默认使用 `curl`,Kibana Dev Tools 风格示例会以 `POST /_search` 形式给出,两种环境都直接可跑。
- **图示**:关键流程图用 Mermaid 描述,建议在支持 Mermaid 的 Markdown 阅读器中查看(例如 GitHub、Typora、VSCode 插件)。
