# 第 15 章 Elasticsearch 插件开发与扩展

## 本章目标

## 15.1 插件是什么

ES 插件 = 符合 ES SPI(Service Provider Interface)规范的 jar 包。
它能在不修改源码的情况下扩展 ES 的能力。

按能力分:

| 类型 | 用途 | 接口 |
| --- | --- | --- |
| **Analysis Plugin** | 自定义分词器、字符过滤器、token filter | `Plugin` + `AnalysisPlugin` |
| **Ingest Plugin** | 自定义数据预处理 | `IngestPlugin` |
| **REST Plugin** | 自定义 HTTP 端点 | `RestHandler` + `BaseRestHandler` |
| **Script Plugin** | 自定义脚本语言 | `ScriptPlugin` |
| **Discovery Plugin** | 自定义节点发现 | `DiscoveryPlugin` |

> 8.x 起插件推荐用 **Gradle + elasticsearch-plugin-cli** 工具链。

## 15.3 示例:写一个简单的 REST 插件

我们做一个返回 "pong" 的端点 `GET /_myplugin/ping`。

### 15.3.1 目录结构

```
rest-handler/
├── build.gradle
├── settings.gradle
└── src/main/java/
    └── org/elasticsearch/example/resthandler/
        ├── ExampleRestHandlerPlugin.java
        └── PingRestAction.java
```

### 15.3.2 插件类

`ExampleRestHandlerPlugin.java`:

```java
package org.elasticsearch.example.resthandler;

import org.elasticsearch.plugin.RestPlugin;
import org.elasticsearch.plugins.Plugin;

import java.util.List;
import java.util.function.Supplier;

public class ExampleRestHandlerPlugin extends Plugin implements RestPlugin {

    @Override
    public List<RestHandler> getRestHandlers(Settings settings, RestController restController,
                                              ClusterSettings clusterSettings,
                                              IndexScopedSettings indexScopedSettings,
                                              SettingsFilter settingsFilter,
                                              IndexNameExpressionResolver indexNameExpressionResolver,
                                              Supplier<DiscoveryNodes> nodesInCluster) {
        return List.of(new PingRestAction());
    }
}
```

### 15.3.3 REST Action

`PingRestAction.java`:

```java
package org.elasticsearch.example.resthandler;

import org.elasticsearch.client.internal.node.NodeClient;
import org.elasticsearch.rest.BaseRestHandler;
import org.elasticsearch.rest.RestRequest;
import org.elasticsearch.rest.RestStatus;
import org.elasticsearch.xcontent.XContentBuilder;

import java.io.IOException;
import java.util.List;

import static org.elasticsearch.rest.RestRequest.Method.GET;

public class PingRestAction extends BaseRestHandler {

    @Override public String getName() { return "ping_action"; }

    @Override
    public List<Route> routes() {
        return List.of(new Route(GET, "/_myplugin/ping"));
    }

    @Override
    protected RestChannelConsumer prepareRequest(RestRequest request, NodeClient client) throws IOException {
        return channel -> {
            XContentBuilder builder = channel.newBuilder();
            builder.startObject().field("status", "pong").endObject();
            channel.sendResponse(new RestResponse(RestStatus.OK, builder));
        };
    }
}
```

### 15.3.4 build.gradle

`build.gradle`:

```groovy
plugins {
  id 'java'
  id 'elasticsearch.esplugin'
}

esplugin {
  name    'rest-handler'
  description 'A custom REST handler'
  classname 'org.elasticsearch.example.resthandler.ExampleRestHandlerPlugin'
}

repositories {
  mavenCentral()
}

dependencies {
  implementation 'org.elasticsearch:elasticsearch:8.13.4'
}
```

### 15.3.5 构建 & 安装

```bash
./gradlew bundlePlugin
# 产物:build/distributions/rest-handler-8.13.4.zip

# 安装到 ES
./bin/elasticsearch-plugin install file:///path/to/rest-handler-8.13.4.zip
```

### 15.3.6 验证

```bash
curl -u elastic:pass http://localhost:9200/_myplugin/ping
# {"status":"pong"}
```

## 15.4 示例:自定义分词器插件

**场景**:英文文本中,把 `e-commerce` 切成 `["e", "commerce"]`,或者保持原样。

`MyAnalyzerProvider.java`:

```java
public class MyAnalyzerProvider extends AbstractIndexAnalyzerProvider<MyAnalyzer> {

    private final MyAnalyzer analyzer;

    public MyAnalyzerProvider(IndexSettings indexSettings, Environment env, String name, Settings settings) {
        super(indexSettings, name, settings);
        analyzer = new MyAnalyzer();
    }

    @Override public MyAnalyzer get() { return analyzer; }
}
```

`MyAnalyzer.java`:

```java
public class MyAnalyzer extends Analyzer {

    @Override protected TokenStreamComponents createComponents(String fieldName) {
        Tokenizer src = new WhitespaceTokenizer();
        TokenStream filter = new LowerCaseFilter(src);
        return new TokenStreamComponents(src, filter);
    }
}
```

插件注册:

```java
@Override
public Map<String, AnalysisProvider<AnalyzerProvider<? extends Analyzer>>> getAnalyzers() {
    return Map.of("my_analyzer", MyAnalyzerProvider::new);
}
```

> 在 mapping 用 `"analyzer": "my_analyzer"`。

## 15.5 示例:Ingest Processor 插件

**场景**:在写入前把 `name` 转大写。

```java
public class UppercaseProcessor extends AbstractProcessor {

    public static final String TYPE = "uppercase";

    private final String field;

    public UppercaseProcessor(String tag, String description, String field) {
        super(tag, description);
        this.field = field;
    }

    @Override
    public IngestDocument execute(IngestDocument document) {
        Object value = document.getFieldValue(field, Object.class, true);
        if (value instanceof String s) {
            document.setFieldValue(field, s.toUpperCase(Locale.ROOT));
        }
        return document;
    }

    @Override public String getType() { return TYPE; }
}

public class UppercaseProcessorFactory implements Processor.Factory {

    @Override
    public UppercaseProcessor create(Map<String, Processor.Factory> registry, String tag, String description, Map<String, Object> config) {
        String field = (String) config.get("field");
        return new UppercaseProcessor(tag, description, field);
    }
}
```

注册:

```java
@Override
public Map<String, Processor.Factory> getProcessors(Processor.Parameters parameters) {
    return Map.of(UppercaseProcessor.TYPE, new UppercaseProcessorFactory());
}
```

使用:

```
PUT /_ingest/pipeline/upper-pipe
{
  "processors": [
    { "uppercase": { "field": "name" } }
  ]
}

PUT /my_index/_doc/1?pipeline=upper-pipe
{ "name": "alice" }
# 存进 _source 的 name: "ALICE"
```

## 15.6 Native 插件(高级)

## 15.7 插件发布

### 15.7.1 测试

写 `RestIT.java` 用 ES IntegTest 框架跑集成测试。

### 15.7.2 签名

生产 ES 默认禁非签名插件(`xpack.security.enabled: true` + `plugins.enforce_strict_plugin_signing: true`)。

签名:

```bash
./bin/elasticsearch-plugin install --sign --keystore /path/to/keystore.p12 \
  file:///path/to/plugin.zip
```

> 商业用户可走 Elastic 官方签名(提交给 Elastic 审核)。

### 15.7.3 私有仓库

企业内可搭 Maven 私服,放自家插件。

## 15.8 常见问题

| 问题 | 解决 |
| --- | --- |
| 插件加载失败:ClassNotFound | `plugin-descriptor.properties` 路径 / classname 写错 |
| 找不到 ES 依赖 | `build.gradle` 引入 `elasticsearch` 依赖 |
| 启动后 503 | SPI 注册不全 |
| 签名错误 | `--sign` 不用 / 私钥不一致 |
| `unsigned` 警告 | `plugins.enforce_strict_plugin_signing: false`(仅测试) |
