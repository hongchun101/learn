## 每章统一结构

每个主题文档都按以下骨架展开,便于聚焦:

1. **核心思想** — 一句话定位
2. **协议/流程** — 时序图 + 状态机
3. **故障矩阵** — 节点失效 / 网络分区 / 超时的应对
4. **代码示例** — 可落地的最小代码
5. **优点 / 缺点** — 维度对比表
6. **与其他方案对比** — 横向
7. **面试高频问题** — 答案要点
8. **参考资料** — 论文 / 官方文档 / 源码

> 不要只读一篇:每个问题在多篇中互为佐证(如 TCC 的异常在 04 + 11,框架选择在 10 + 13)。
