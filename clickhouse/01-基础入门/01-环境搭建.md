# 第 1 章：环境搭建与第一个查询

## 1.1 ClickHouse 是什么

ClickHouse 是俄罗斯 Yandex 公司开源的**列式数据库管理系统（DBMS）**，专为**在线分析处理（OLAP）** 设计。它能在一台普通服务器上：
- 1 秒处理 10 亿+ 行数据
- 写入速度达 100 万-200 万行/秒
- 压缩比 5-10 倍于原始数据

### 核心优势
```
传统 MySQL（行存储）        ClickHouse（列存储）
┌────────────────┐         ┌────────────────┐
│ id│name │age  │         │ id1│id2│id3│..│
│ 1 │张三 │25  │         │ 1  │2  │3  │..│
│ 2 │李四 │30  │         │ 张三│李四│王五│
└────────────────┘         │ 25 │30 │28 │
查询需要读整行              └────────────────┘
                            只扫描需要的列（id, age）
```

## 1.2 三种安装方式

### 方式 1：Docker 启动（推荐新手）

```bash
# 拉取官方镜像
docker pull clickhouse/clickhouse-server:24.3

# 启动服务端
docker run -d --name clickhouse-server \
  -p 9000:9000 \    # 原生协议端口
  -p 8123:8123 \    # HTTP 协议端口
  -p 9009:9009 \    # 跨节点复制端口
  -e CLICKHOUSE_DB=default \
  -e CLICKHOUSE_USER=default \
  -e CLICKHOUSE_PASSWORD=123456 \
  -e CLICKHOUSE_DEFAULT_ACCESS_MANAGEMENT=1 \
  -v ${PWD}/data:/var/lib/clickhouse \
  -v ${PWD}/logs:/var/log/clickhouse-server \
  clickhouse/clickhouse-server:24.3

# 安装客户端（另一个终端）
docker pull clickhouse/clickhouse-client:24.3

# 连接服务器
docker run -it --rm --link clickhouse-server:clickhouse-server \
  clickhouse/clickhouse-client:24.3 \
  --host clickhouse-server \
  --user default \
  --password 123456
```

### 方式 2：原生安装（Linux）

```bash
# Ubuntu/Debian
sudo apt-get install -y apt-transport-https ca-certificates dirmngr
GNUPG=$(mktemp) && wget -qO- https://keyserver.ubuntu.com/pks/lookup?op=get&search=0x8919F6BD2B48D754 | gpg --dearmor > $GNUPG
sudo mv $GNUPG /usr/share/keyrings/clickhouse-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/clickhouse-keyring.gpg] https://packages.clickhouse.com/deb stable main" | \
  sudo tee /etc/apt/sources.list.d/clickhouse.list

sudo apt-get update
sudo apt-get install -y clickhouse-server clickhouse-client

# 启动服务
sudo service clickhouse-server start
clickhouse-client  # 默认无密码连接
```

### 方式 3：macOS 快速体验

```bash
brew install clickhouse
clickhouse-server  # 启动
clickhouse-client  # 连接
```

## 1.5 配置详解

ClickHouse 配置文件路径：
- `/etc/clickhouse-server/config.xml`（主配置）
- `/etc/clickhouse-server/config.d/*.xml`（用户配置，推荐）

### 关键配置模板

```xml
<!-- /etc/clickhouse-server/config.d/00-base.xml -->
<clickhouse>
    <!-- 监听地址（生产环境绑定内网） -->
    <listen_host>0.0.0.0</listen_host>

    <!-- HTTP 端口 -->
    <http_port>8123</http_port>
    <tcp_port>9000</tcp_port>
    <mysql_port>9004</mysql_port>
    <interserver_http_port>9009</interserver_http_port>

    <!-- 监听 MySQL 协议（兼容 MySQL 客户端） -->
    <listen_host>::1</listen_host>
    <mysql_port>9004</mysql_port>

    <!-- 路径配置 -->
    <path>/var/lib/clickhouse/</path>
    <tmp_path>/var/lib/clickhouse/tmp/</tmp_path>

    <!-- 用户配置（建议显式声明） -->
    <users_config>users.xml</users_config>
    <default_profile>default</default_profile>

    <!-- 远程端口（用于跨节点通信） -->
    <openSSL>
        <server>
            <certificateFile>/etc/clickhouse-server/server.crt</certificateFile>
            <privateKeyFile>/etc/clickhouse-server/server.key</privateKeyFile>
            <verificationMode>none</verificationMode>
            <loadDefaultCAFile>true</loadDefaultCAFile>
            <cacheSessions>true</cacheSessions>
            <disableProtocols>sslv2,sslv3</disableProtocols>
            <preferServerCiphers>true</preferServerCiphers>
        </server>
    </openSSL>
</clickhouse>
```

## 1.6 第一个建表与查询

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS tutorial;

-- 创建表（MergeTree 引擎，CH 最核心的引擎）
CREATE TABLE tutorial.events
(
    event_date Date,
    event_time DateTime,
    user_id   UInt64,
    event_type LowCardinality(String),
    product_id UInt32,
    amount Decimal(10, 2)
)
ENGINE = MergeTree
PARTITION BY toYYYYMM(event_date)
ORDER BY (event_type, user_id)
SETTINGS index_granularity = 8192;

-- 插入数据
INSERT INTO tutorial.events VALUES
    ('2024-01-01', '2024-01-01 10:00:00', 1001, 'view', 2001, 0.00),
    ('2024-01-01', '2024-01-01 10:05:00', 1001, 'click', 2001, 0.00),
    ('2024-01-01', '2024-01-01 10:10:00', 1001, 'purchase', 2001, 99.50),
    ('2024-01-01', '2024-01-01 11:00:00', 1002, 'view', 2002, 0.00);

-- 第一个查询：每种事件类型的总数
SELECT
    event_type,
    count() AS cnt,
    uniqExact(user_id) AS uv,
    sum(amount) AS total_amount
FROM tutorial.events
WHERE event_date = '2024-01-01'
GROUP BY event_type
ORDER BY cnt DESC;
```

**预期结果**：
```
event_type | cnt | uv  | total_amount
-----------+-----+-----+-------------
view       | 2   | 2   | 0.00
click      | 1   | 1   | 0.00
purchase   | 1   | 1   | 99.50
```

## 1.7 关键参数对比测试

```sql
-- 单条 vs 批量写入对比
-- 单条
INSERT INTO tutorial.events VALUES ('2024-01-02', '2024-01-02 10:00:00', 1003, 'view', 2003, 0.00);

-- 批量（推荐）

    ('2024-01-02', '2024-01-02 10:02:00', 1004, 'click', 2004, 0.00);
-- 批量 1000+ 行性能提升 100 倍
```

## 1.8 实战：生成百万级测试数据

```sql
-- 快速生成 100 万行测试数据
INSERT INTO tutorial.events
SELECT
    toDate('2024-01-01') + (number % 30) AS event_date,
    toDateTime('2024-01-01 00:00:00') + (number % 86400) AS event_time,
    number % 10000 AS user_id,
    arrayElement(['view', 'click', 'purchase', 'add_to_cart'], (number % 4) + 1) AS event_type,
    number % 1000 AS product_id,
    round(rand() / 100, 2) AS amount
FROM numbers(1000000);

-- 查询性能测试
SELECT count() FROM tutorial.events;  -- 应返回 1000004
```
