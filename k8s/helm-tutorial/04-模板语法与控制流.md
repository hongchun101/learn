# 04. 模板语法与控制流

Helm 模板 = Go template + Sprig 函数库 + 100+ 专属函数。掌握模板语法是从"会用"到"精通"的分水岭。

## 4.1 基本语法

```yaml
# {{ }} 是动作(action),会被求值
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ .Release.Name }}-config
data:
  # 字符串字面量
  greeting: "hello"

  # 变量插值
  who: {{ .Values.app.name }}

  # 管道 + 函数
  key: {{ .Values.app.key | default "default-key" | quote }}
```

## 4.2 空白控制:这是新手最容易踩的坑

`{{ }}` 渲染时会**保留前后空白**。解决方案是 `{{-` 和 `-}}`(左/右 trim)。

```yaml
# ❌ 错误:会多出空行
metadata:
  name: {{ .Values.name }}
  labels:
    app: {{ .Values.app }}
# 输出:
# metadata:
#   name: nginx
#
#   labels:
#     app: web
#

# ✅ 正确:用 -} 吃掉右侧空白
metadata:
  name: {{ .Values.name }}
  labels:
    app: {{ .Values.app }}
# 输出:
# metadata:
#   name: nginx
#   labels:
#     app: web
```

```yaml
# 完整 trim 例子
{{- if .Values.enabled }}     # {{- 吃掉左侧
resource: enabled
{{- end }}                     # -}} 吃掉右侧
```

**约定**:模板里**每个动作都用 trim**,既可读又干净。

## 4.3 变量

```yaml
# 局部变量:在 action 内,用 $ 引用
{{- $releaseName := .Release.Name -}}
{{- $fullName := include "myapp.fullname" . -}}
metadata:
  name: {{ $fullName }}
  namespace: {{ .Release.Namespace }}
  labels:
    app.kubernetes.io/managed-by: {{ $releaseName }}
```

```yaml
# 变量在 range 内会覆盖外层
{{- range $key, $val := .Values.servers }}
- name: {{ $key }}
  port: {{ $val.port }}
{{- end }}
```

## 4.4 if/else if/else

```yaml
{{- if .Values.serviceAccount.create }}
apiVersion: v1
kind: ServiceAccount
metadata:
  name: {{ include "myapp.fullname" . }}
{{- end }}
```

```yaml
{{- if eq .Values.service.type "LoadBalancer" }}
  externalTrafficPolicy: Local
{{- else if eq .Values.service.type "NodePort" }}
  externalTrafficPolicy: Cluster
{{- else }}
  clusterIP: None
{{- end }}
```

### 零值判断

```yaml
# 模板里,以下都是"假":
#   false  0  ""  nil  empty list  empty map
# 其它都是"真"

# 用 with 简化嵌套判断
{{- with .Values.resources }}
resources:
  {{- toYaml . | nindent 4 }}
{{- end }}

# 等价于:
{{- if .Values.resources }}
resources:
  {{- toYaml .Values.resources | nindent 4 }}
{{- end }}
```

## 4.5 with:进入上下文,简化引用

```yaml
{{- with .Values.ingress }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ $.Release.Name }}-ingress
  annotations:
    {{- range $key, $val := .annotations }}
    {{ $key }}: {{ $val | quote }}
    {{- end }}
spec:
  {{- if .className }}
  ingressClassName: {{ .className }}
  {{- end }}
  rules:
    {{- range .hosts }}
    - host: {{ .host | quote }}
      http:
        paths:
          {{- range .paths }}
          - path: {{ .path }}
            pathType: {{ .pathType }}
            backend:
              service:
                name: {{ $.Release.Name }}
                port:
                  number: {{ $.Values.service.port }}
          {{- end }}
    {{- end }}
{{- end }}
```

**关键点**:
- `with .` 后,内部的 `.` 变为 `with` 的值
- 访问**父级**对象用 `$.`(根)或 `$variable`(命名变量)

## 4.6 range:循环

```yaml
# 遍历 map
{{- range $env, $config := .Values.env }}
- name: {{ $env }}
  value: {{ $config.value | quote }}
{{- end }}
```

```yaml
# 遍历 list
{{- range .Values.volumes }}
- name: {{ .name }}
  emptyDir: {}
{{- end }}
```

```yaml
# 数字范围
{{- range until 3 }}
- host: web-{{ . }}.example.com
{{- end }}
# 生成 web-0/web-1/web-2
```

```yaml
# tuple 模拟
{{- range $i, $svc := list "api" "web" "worker" }}
- name: {{ $svc }}
  port: {{ add 8000 $i }}
{{- end }}
```

## 4.7 限定符 $ 和作用域

`$` 指向根上下文,**不会随 with/range 改变**。

```yaml
# 坑:range 里的 . 是当前迭代元素
{{- range .Values.pods }}
metadata:
  name: {{ .name }}        # . 指向当前 pod 对象
  namespace: {{ $.Release.Namespace }}  # $ 指向根,拿到 Release
{{- end }}
```

```yaml
# with 块里也是
{{- with .Values.ingress }}
rules:
  - host: {{ .host }}          # .host 是 ingress.hosts[0].host
    http:
      backend:
        serviceName: {{ $.Values.service.name }}  # $.Values 还是根
{{- end }}
```

## 4.8 综合实战:一个真实的 Deployment

```yaml
{{- /* 注释:helm 不会输出 */ -}}
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ include "myapp.fullname" . }}
  labels:
    {{- include "myapp.labels" . | nindent 4 }}
spec:
  {{- if not .Values.autoscaling.enabled }}
  replicas: {{ .Values.replicaCount }}
  {{- end }}
  selector:
    matchLabels:
      {{- include "myapp.selectorLabels" . | nindent 6 }}
  template:
    metadata:
      labels:
        {{- include "myapp.selectorLabels" . | nindent 8 }}
      {{- with .Values.podLabels }}
        {{- toYaml . | nindent 8 }}
      {{- end }}
      annotations:
        # 检查 checksum 触发滚动升级
        checksum/config: {{ include (print $.Template.BasePath "/configmap.yaml") . | sha256sum }}
        {{- with .Values.podAnnotations }}
        {{- toYaml . | nindent 8 }}
        {{- end }}
    spec:
      {{- with .Values.imagePullSecrets }}
      imagePullSecrets:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      serviceAccountName: {{ include "myapp.serviceAccountName" . }}
      {{- with .Values.podSecurityContext }}
      securityContext:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      containers:
        - name: {{ .Chart.Name }}
          {{- with .Values.securityContext }}
          securityContext:
            {{- toYaml . | nindent 8 }}
          {{- end }}
          image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
          imagePullPolicy: {{ .Values.image.pullPolicy }}
          ports:
            - name: http
              containerPort: {{ .Values.service.port }}
              protocol: TCP
          {{- with .Values.livenessProbe }}
          livenessProbe:
            {{- toYaml . | nindent 12 }}
          {{- end }}
          {{- with .Values.readinessProbe }}
          readinessProbe:
            {{- toYaml . | nindent 12 }}
          {{- end }}
          resources:
            {{- toYaml .Values.resources | nindent 12 }}
          env:
            - name: POD_NAME
              valueFrom:
                fieldRef:
                  fieldPath: metadata.name
            {{- with .Values.extraEnv }}
            {{- toYaml . | nindent 12 }}
            {{- end }}
          volumeMounts:
            - name: config
              mountPath: /etc/config
      volumes:
        - name: config
          configMap:
            name: {{ include "myapp.fullname" . }}
      {{- with .Values.nodeSelector }}
      nodeSelector:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      {{- with .Values.affinity }}
      affinity:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      {{- with .Values.tolerations }}
      tolerations:
        {{- toYaml . | nindent 8 }}
      {{- end }}
```

## 4.9 模板调试技巧

```bash
# 1. 渲染到 stdout(不连接集群)
helm template myrelease ./mychart

# 2. 输出到文件
helm template myrelease ./mychart > rendered.yaml

# 3. 显示计算后的 values
helm template myrelease ./mychart --show-only templates/deployment.yaml

# 4. 模拟服务器端渲染
helm template myrelease ./mychart --validate \
  --set nameOverride=myapp \
  -f values-prod.yaml
```

## 4.10 常见错误速查

| 错误 | 原因 | 解决 |
|------|------|------|
| `function "x" not defined` | 函数名拼错/不存在 | 用 `helm template --debug` 看堆栈 |
| `can't evaluate field X in type interface {}` | 字段不存在或类型不对 | 检查 values 类型 |
| `template: ...: unexpected "}"` | 括号不匹配 | 找 `{{` 数量对得上 `}}` |
| 渲染出 `<no value>` | 字段是 nil | 用 `default` 函数或 `if` 判断 |
| yaml 缩进乱了 | 没正确 `nindent` | 用 `nindent N`(会自动加换行) |

## 4.11 本章小结

- `{{ }}` 是动作,`{{-` `-}}` 控制空白
- `with` 简化嵌套但要小心 `.` 的变化,用 `$.` 访问根
- `range` 遍历集合,内 `.` 指向当前元素
- `if/else` 配合零值判断做条件渲染
- 复杂模板多用 `include` + `_helpers.tpl` 拆解(见下章)
- `nindent N` = "先换行再缩进 N 个空格",缩进 yaml 的标准动作
