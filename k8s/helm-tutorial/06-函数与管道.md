# 06. 函数与管道

Helm 内置 100+ 函数,加上 Sprig 的 70+,理解函数是写复杂模板的前提。

## 6.1 管道的本质

```yaml
# 管道:把左侧结果作为第一个参数传给右侧函数
{{ .Values.name | quote }}
# 等价于
{{ quote .Values.name }}

# 多级管道
{{ .Values.name | default "anonymous" | quote | upper }}
# 等价于
{{ quote (upper (default "anonymous" .Values.name)) }}
```

**规则**:管道从左到右执行,左边的值**作为**右函数的**最后一个参数**(Go template 习惯)。

```go
// 不是 f(a, b, c) 而是 c |> f(a, b) => f(a, b, c)
```

## 6.2 函数分类速查表

### 字符串函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `quote` / `squote` | 加双/单引号 | `{{ "foo" \| quote }}` → `"foo"` |
| `upper` / `lower` / `title` | 大小写 | `{{ "foo" \| upper }}` → `FOO` |
| `trim` / `trimAll` / `trimPrefix` / `trimSuffix` | 去除空白/字符 | `{{ "-foo-" \| trimPrefix "-" }}` → `foo-` |
| `trunc` / `trunc 63` | 截断到 N 字符 | `{{ "verylong" \| trunc 5 }}` → `veryl` |
| `substr` | 子串 | `{{ "hello" \| substr 1 3 }}` → `el` |
| `replace` | 替换 | `{{ "foo" \| replace "o" "0" }}` → `f00` |
| `repeat` | 重复 | `{{ "a" \| repeat 3 }}` → `aaa` |
| `contains` | 包含 | `{{ "foobar" \| contains "oba" }}` → `true` |
| `hasPrefix` / `hasSuffix` | 前缀/后缀 | `{{ "foobar" \| hasPrefix "foo" }}` → `true` |
| `split` / `splitList` | 切分 | `{{ splitList "." "a.b.c" }}` → `[a b c]` |
| `join` | 连接 | `{{ join "-" (list "a" "b" "c") }}` → `a-b-c` |
| `b64enc` / `b64dec` | Base64 | `{{ "foo" \| b64enc }}` → `Zm9v` |
| `sha256sum` | SHA256 | `{{ "foo" \| sha256sum }}` → `2c26b4...` |
| `randAlphaNum` | 随机字符串 | `{{ randAlphaNum 8 }}` → `aB3xY9qZ` |
| `printf` | 格式化 | `{{ printf "%s-%s" "foo" "bar" }}` → `foo-bar` |

### 数值函数

| 函数 | 作用 |
|------|------|
| `add` / `sub` / `mul` / `div` / `mod` | 算术 |
| `max` / `min` | 最大最小 |
| `ceil` / `floor` / `round` | 取整 |
| `int` / `int64` / `float64` | 类型转换 |

```yaml
replicas: {{ add 2 .Values.baseReplicas }}
```

### 列表函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `list` | 构造列表 | `(list "a" "b")` |
| `first` / `last` / `rest` / `initial` | 取元素 | `{{ first (list 1 2 3) }}` → `1` |
| `append` / `prepend` | 追加 | `{{ append (list "a") "b" }}` → `[a b]` |
| `concat` | 拼接 | `{{ concat (list 1) (list 2) }}` → `[1 2]` |
| `len` | 长度 | `{{ len (list 1 2 3) }}` → `3` |
| `has` | 包含 | `{{ has "b" (list "a" "b") }}` → `true` |
| `uniq` | 去重 | `{{ uniq (list "a" "b" "a") }}` → `[a b]` |
| `sortAlpha` | 排序 | `{{ sortAlpha (list "c" "a" "b") }}` → `[a b c]` |
| `compact` | 去掉空 | `{{ compact (list "a" "" "b") }}` → `[a b]` |
| `without` | 排除 | `{{ without (list "a" "b" "c") "b" }}` → `[a c]` |
| `index` | 按下标取 | `{{ index (list "a" "b" "c") 1 }}` → `b` |

### 字典函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `dict` | 构造字典 | `(dict "k1" "v1" "k2" "v2")` |
| `get` | 取值 | `{{ get $dict "k1" }}` |
| `set` | 设置 | `{{ $d := set $dict "k3" "v3" }}` |
| `unset` | 删除 | `{{ $d := unset $dict "k1" }}` |
| `hasKey` | 包含 | `{{ hasKey $dict "k1" }}` |
| `keys` / `values` | 取 keys/values | `{{ keys $dict }}` |
| `merge` | 合并 | `{{ merge $d1 $d2 }}` |
| `pluck` | 提取字段 | `{{ pluck "name" $d1 $d2 }}` |
| `deepCopy` | 深拷贝 | `{{ $d2 := deepCopy $d1 }}` |

```yaml
# 构造并合并字典:模拟多参数函数
{{- $args := dict "name" .Values.name "tag" .Values.tag "registry" "docker.io" -}}
image: {{ include "myapp.image" $args }}
```

### 默认值 / 必备判断

| 函数 | 作用 |

## 6.4 关键函数深度讲解

### `lookup` — 读集群已存在资源

```yaml
# 查已存在的 ConfigMap(需要在 helm install 时才能用,template 不可用)
{{- $existing := lookup "v1" "ConfigMap" .Release.Namespace "my-config" -}}
{{- if $existing }}
data:
  existing-key: {{ index $existing.data "key" | quote }}
{{- else }}
data:
  new-key: "default"
{{- end }}
```

### `required` — 必备值检查

```yaml
# 没设 image.repository 时,helm 会报错并显示这个提示
image: {{ required "image.repository is required" .Values.image.repository }}:{{ .Values.image.tag }}
```

### `tpl` — 字符串作为模板再渲染

```yaml
# values 里可以放模板字符串,运行时再渲染
env:
  - name: GREETING
    value: {{ tpl .Values.greeting . }}

# values.yaml:
greeting: "Hello {{ .Release.Name }}"
```

### `toYaml` + `nindent` — 模板的"瑞士军刀"

```yaml
# 任何 map/slice,直接转 yaml 并缩进
spec:
  {{- with .Values.ingress.annotations }}
  annotations:
    {{- toYaml . | nindent 4 }}
  {{- end }}

# nindent N = "\n" + 4*N 空格
# indent N  = 4*N 空格(不换行)
```

## 6.5 函数实战:动态生成多份 Secret

```yaml
{{- range $name, $cfg := .Values.tls }}
{{- $secret := lookup "v1" "Secret" $.Release.Namespace $name }}
{{- if $secret }}
apiVersion: v1
kind: Secret
metadata:
  name: {{ $name }}
type: kubernetes.io/tls
data:
  tls.crt: {{ index $secret.data "tls.crt" }}
  tls.key: {{ index $secret.data "tls.key" }}
---
{{- end }}
{{- end }}
```

## 6.6 性能注意

- 模板渲染在客户端,**没特别性能问题**
- 但 `lookup` 会在每次 `helm upgrade` 时调 apiserver,**慢**且有失败风险
- 避免在 hook 里用 `lookup`(hook 运行时 release 状态特殊)
- 大型 Chart(100+ 模板)考虑 `helm template --debug` 排查渲染时间

## 6.8 常用函数速记

```yaml
# 1. 安全取嵌套值
{{- $port := dig "service" "port" 80 .Values -}}

# 2. 生成随机后缀(避免冲突)
{{- $suffix := randAlphaNum 5 | lower -}}

# 3. 字节单位转换
{{- $memBytes := "1Gi" | memory | humanize -}}

# 4. 时间格式
{{- now | date "2006-01-02" -}}

# 5. 验证邮箱(自定义函数,标准库没有)
```

## 6.9 本章小结

- 管道:左侧结果作为右侧函数的**最后一个**参数
- 100+ Helm 函数 + 100+ Sprig 函数
- `toYaml | nindent N` 是渲染 map 的标准动作
- `default` / `required` 处理值缺失
- `dict` 模拟多参数,`tpl` 实现递归模板,`lookup` 读集群状态
- 性能上 `lookup` 是慢操作,慎用
