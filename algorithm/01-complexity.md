# 01 · 复杂度分析

> 用 30 分钟建立严格的复杂度直觉,这是 LeetCode 2000 题的入场券。

---

## 1. 时间复杂度

### 大 O 记号(渐近上界)

`T(n) = O(f(n))` 表示存在常数 C, n0, 使得 n > n0 时 T(n) ≤ C·f(n)。

| 记号 | 含义 | 示例 |
|------|------|------|
| O(1) | 常数 | 哈希表查找 |
| O(log n) | 对数 | 二分查找 |
| O(√n) | 根号 | 分解质因数 |
| O(n) | 线性 | 一次遍历 |
| O(n log n) | 线性对数 | 归并排序 |
| O(n^2) | 平方 | 双重循环 |
| O(n^3) | 立方 | Floyd |
| O(2^n) | 指数 | 子集枚举 |
| O(n!) | 阶乘 | 全排列 |

### 常见规模反推

| n | 可接受复杂度 |
|---|------------|
| n ≤ 10 | O(n!) |
| n ≤ 20 | O(2^n) |
| n ≤ 500 | O(n^3) |
| n ≤ 5000 | O(n^2) |
| n ≤ 10^6 | O(n log n) 或 O(n) |
| n ≤ 10^9 | O(log n) 或 O(√n) |

## 2. 空间复杂度

不仅算"数据",还看"递归栈":

```python
def dfs(node):
    if not node: return
    dfs(node.left)
    dfs(node.right)
# 递归深度 = 树高,空间 O(h)
```

### 空间换时间决策表

| 数据规模 | 允许空间 |
|---------|---------|
| 一般 | O(n) |
| 内存限制严 | O(1) 或 O(log n) |
| 极小(嵌入式) | O(1) |

## 3. 均摊分析(Amortized)

**例**:动态数组 push_back,偶发扩容 O(n),但 N 次总 O(N),均摊 O(1)。

均摊分析方法:
- **聚合法**(Aggregate):总操作 / 操作数
- **记账法**(Accounting):不同操作赋不同"代价"
- **势能法**(Potential):维护一个势能函数

### 常见均摊 O(1) 的数据结构

- 动态数组 push_back / pop_back
- 单调栈/单调队列(每次只 push/pop 一次)
- 并查集路径压缩后(均摊接近 O(α(n)))
- 哈希表(扩容)
- 栈操作中配对的 push/pop

---

## 4. 势能法范例

**题目**:栈支持 push/pop/multipop(弹出 k 个)操作,证明 multipop 整体均摊 O(1)。

**势能函数**:`Φ = 栈中元素个数`

- push:实际代价 1,势能 +1,均摊 2 = O(1)
- pop:实际代价 1,势能 -1,均摊 0 = O(1)
- multipop(k):实际代价 k,势能 -k,均摊 0 = O(1)

## 5. 复杂度递归式求解

### 主定理(Master Theorem)

`T(n) = aT(n/b) + O(n^d)`

| 情况 | 条件 | 结果 |
|------|------|------|
| 1 | d > log_b a | O(n^d) |
| 2 | d = log_b a | O(n^d log n) |
| 3 | d < log_b a | O(n^(log_b a)) |

### 例:归并排序

T(n) = 2T(n/2) + O(n)
a=2, b=2, d=1 → d = log_b a = 1 → O(n log n) ✓

### 例:二分查找

T(n) = T(n/2) + O(1)
a=1, b=2, d=0 → d = log_b a = 0 → O(log n) ✓

## 6. 对数复杂度识别

出现以下特征,复杂度**必然带 log**:
- 每轮问题规模除以 2
- 树高 = log n
- 堆操作
- 平衡树查找

## 7. 实战:LeetCode 上如何倒推解法

```python
def solve(nums):
    n = len(nums)
    # n ≤ 10^5 → 期望 O(n) 或 O(n log n)
    # n ≤ 10^9 → 必须 O(log n)
```

- n ≤ 10^4 → O(n^2) 可过(双重循环)
- 进阶要求 O(n) → 哈希表

证明某问题**不可能**更快:
- 决策树(比较排序 Ω(n log n))
- 信息论(最少需要 bit 数)
- 归约(归约到已知下界问题)
