## 🎯 学习路径推荐

```
入门(0-3 个月):
  - MDN 教程
  - freeCodeCamp
  - HTML/CSS 实战项目

进阶(3-12 个月):
  - JavaScript 高级程序设计
  - React/Vue 官方教程 + 实战
  - 算法 + 数据结构(LeetCode 200 题)
  - 1-2 个完整项目

专家(1 年+):
  - 框架源码
  - 浏览器/网络原理
  - 系统设计
  - 开源贡献
  - 技术写作 / 分享
```

## ✨ 推荐博客模板

自己的博客应该包含:
- 项目经验(技术栈、难点、决策、结果)
- 源码分析(具体到代码片段)
- 最佳实践总结
- 踩坑记录(具体场景、解决方案)
- 技术选型分析(对比、决策依据)

写博客 → 倒逼学习 → 形成正循环。
